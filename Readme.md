# Rosalind Problems

This repository contains my solutions to problems from the [Rosalind](https://rosalind.info/) bioinformatics platform.  
More will be added over time as I continue working through the problem sets.

## Topics Covered

**Bioinformatics Stronghold:**
- ORFs (Open Reading Frames)  
- DNA/RNA transcription and translation  
- Motif searching  
- Sequence alignment (distance/scoring)  
- Other fundamental bioinformatics problems  

## Usage

Each Python script is standalone and solves a single Rosalind problem.
Some input files are included; others can be downloaded directly from Rosalind.

```bash
python path/to/script.py input.txt
```
